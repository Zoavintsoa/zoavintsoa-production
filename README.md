# Zoavintsoa Production

Site portfolio de **Zoavintsoa Production** — Photography · Filmmaking · Visual Creation.

## Structure
- `index.html` — page principale
- `css/style.css` — design responsive
- `js/script.js` — interactions légères

## Mise à jour du portfolio
Les images de démonstration dans `index.html` sont des images externes temporaires. Elles pourront être remplacées par les photos/vidéos de Zoavintsoa.

## Hébergement
Le site est conçu pour GitHub Pages et ne nécessite ni serveur ni base de données.
